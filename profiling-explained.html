Profiling Data Quality
Compute per-field statistics for every column in every table
~2 min for 35 tables (was 30+ min before optimization)
📊
Query 1: Batched stats (1 query per table)
A single SELECT computes row count, null count, distinct count, min, max, average, and median for ALL columns at once. This replaced 10+ individual queries per column.
-- One query computes ALL stats for ALL columns in a table: SELECT COUNT(*) AS "__row_count", SUM(CASE WHEN "customer_id" IS NULL THEN 1 ELSE 0 END) AS "customer_id__nulls", COUNT(DISTINCT "customer_id") AS "customer_id__distinct", MIN("customer_id") AS "customer_id__min", MAX("customer_id") AS "customer_id__max", AVG("order_total") AS "order_total__avg", -- numeric only PERCENTILE_CONT(0.5) WITHIN GROUP (ORDER BY "order_total") AS "order_total__median", -- numeric only -- ... repeated for every column in the table FROM "orders"
↓
🏆
Query 2: Top values (1 UNION ALL per table)
Gets the 5 most frequent values for each column in a single query using UNION ALL of subqueries.
SELECT * FROM ( SELECT 'customer_id' AS "__field", CAST("customer_id" AS VARCHAR) AS "__val", COUNT(*) AS "__cnt" FROM "orders" WHERE "customer_id" IS NOT NULL GROUP BY "customer_id" ORDER BY "__cnt" DESC LIMIT 5 ) UNION ALL SELECT * FROM ( SELECT 'order_date' AS "__field", CAST("order_date" AS VARCHAR) AS "__val", COUNT(*) AS "__cnt" FROM "orders" WHERE "order_date" IS NOT NULL GROUP BY "order_date" ORDER BY "__cnt" DESC LIMIT 5 ) -- ... UNION ALL for every column
↓
