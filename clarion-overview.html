Introduction

What is Clarion?

Clarion is an AI-native business intelligence platform built for small and medium-sized businesses that want the analytical power of enterprise BI tools — without the complexity, cost, or need for a dedicated data team.

Most businesses sit on a goldmine of data locked inside accounting software, CRM systems, ERP platforms, and databases. Extracting meaningful insights from that data traditionally requires data engineers, SQL developers, or expensive consultants. Clarion removes that barrier entirely.

Using state-of-the-art AI (Anthropic's Claude), Clarion understands your data the same way a senior analyst would — the business meaning of each table and column, the relationships between them, your KPI definitions — and then answers your questions in plain language, builds dashboards on demand, and proactively flags issues before they become problems.

The core promise: Any business user — from a CEO to a sales manager — can open Clarion, type a question like "What were my top 10 customers by revenue last quarter?" and receive a clear, accurate answer with a chart, in under five seconds. No training required.

Capabilities

What can Clarion do?

1. Natural Language Questions

Type any business question in plain language — Dutch or English — and Clarion translates it into a precise database query, executes it, and returns a clear answer with a chart or table. There is no query builder, no formula editor, no drag-and-drop interface to learn.

Examples: "Show me revenue by product group for this year vs last year."  ·  "Which customers haven't ordered in the last 60 days?"  ·  "What is my gross margin per salesperson this quarter?"

2. AI-Generated Dashboards

Describe the dashboard you want in a sentence. Clarion designs it, writes all the underlying queries, and renders a fully interactive dashboard — with filters, drill-down, date range selectors, and KPI cards — in under 30 seconds. Dashboards can be saved, shared, and refreshed automatically.

3. Scheduled Email Reports

Any dashboard can be scheduled to arrive in your inbox as a formatted HTML email — daily, weekly, or monthly. The email includes an AI-written executive summary that highlights the key movements and anomalies, so you understand the numbers at a glance before opening the full dashboard.

4. Quality Alerts

Clarion continuously monitors your data for quality issues — missing values, unusual spikes, broken rules — and sends alerts with AI-written business context explaining what changed and why it matters. Not a raw technical error; a plain-language explanation.

5. KPI Drill-Down & Investigation

Click any metric to see the detail rows behind it. Or click "Investigate" on any chart to ask Clarion why a number looks the way it does. The AI fires a series of follow-up queries, identifies the root cause, and returns a synthesised explanation — in seconds.

6. Data Product Modelling

For teams with more complex needs, Clarion can design an optimised star schema data model from your raw source data — fact tables, dimension tables, KPI definitions — and materialise it as a high-speed analytics warehouse. Dashboards and queries run against this warehouse, making even large datasets feel instant.

7. Multi-Source Queries

Connect multiple data sources — accounting, CRM, operations — and ask questions that span all of them. Clarion maintains a knowledge graph of how your data sources relate to each other and can join across them transparently.

8. Role-Based Access

Three role levels — Admin, Analyst, Viewer — ensure that sensitive data and configuration remain accessible only to the right people. Column-level masking and row-level filtering policies can be applied per user or per role.

How It Works

From raw data to business insight

Clarion follows a structured pipeline from data source to insight. Most steps are fully automated — a typical setup takes under an hour.

1

Connect your data source

Point Clarion at your database, ERP, or accounting platform. Supported: PostgreSQL, MySQL, SQL Server, SQLite, ExactOnline, and more. Credentials are encrypted with AES-256 and stored securely.

2

AI generates a semantic layer

Clarion reads your schema and uses AI to generate plain-language descriptions for every table and column, detect relationships, suggest KPI formulas, and score data quality. Your data team reviews and approves — typically in 20 minutes.

3

Ingest to the analytics warehouse

Data is ingested into a high-speed Parquet-based warehouse (Delta Lake). Incremental updates keep it fresh. The warehouse is what Clarion queries — your source systems are never touched during analytics.

4

Ask questions & build dashboards

Business users log in and start asking questions or requesting dashboards immediately. The AI translates every question into precise SQL, executes it, and returns a human-readable answer with a visualisation.

5

Automate delivery

Schedule dashboards as email reports. Set up alerts for quality issues or KPI thresholds. The platform works in the background so you wake up to insight, not raw data.

Safety first: Clarion never exposes raw SQL to business users. Every AI-generated query carries a confidence score — queries below 70% confidence are blocked and logged for review rather than returning a potentially incorrect answer.

Security & Compliance

Enterprise-grade security built in

Clarion was designed with security as a first principle, not an afterthought. Every layer — from credential storage to data access — applies best-practice controls.

  • Credential encryption: All database credentials and API keys are encrypted with AES-256-GCM before storage. Keys are managed through Azure Key Vault.
  • Row-Level Security: PostgreSQL Row-Level Security policies enforce strict tenant isolation at the database level — one tenant can never see another's data, even if application logic fails.
  • Data policies: Admins can define column-level masking (e.g. hide salary data from Viewers) and row-level filters (e.g. sales rep sees only their own customers).
  • JWT authentication: All API calls require a signed JWT token with 8-hour expiry. Passwords are hashed with bcrypt (cost factor 10).
  • No raw SQL to users: Business users never see database queries. A "show query" toggle is available only to admin and analyst roles.
  • Confidence gating: AI-generated queries below 70% confidence are blocked and logged — never executed. This prevents hallucinated or incorrect answers reaching users.
  • GDPR-ready: Data resides entirely in your Azure region (West Europe by default). No data is sent to third-party analytics services.
  • Audit trail: All queries, dashboard accesses, and definition changes are logged with user, timestamp, and tenant context.
  • Rate limiting: API endpoints are rate-limited (200 req/min global, 30 req/min for AI endpoints) to prevent abuse.

GDPR note: The AI (Anthropic Claude) processes only the schema metadata and query results — not the raw personal data in your tables. Personal data never leaves your Azure environment unless you explicitly export it.

Technical Architecture

Built for reliability and scale

Clarion runs entirely on Microsoft Azure, using managed services that scale automatically and require no infrastructure management from the customer.

Deployment

  • Azure Container Apps — backend API, frontend, and ETL pipeline run as containerised services with automatic scaling (scale-to-zero for cost efficiency)
  • Azure PostgreSQL Flexible Server — semantic layer and metadata database, always-on, automated backups
  • Azure Blob Storage — analytics data warehouse (Parquet files), cost-effective, unlimited scale
  • Azure Key Vault — all secrets and encryption keys, zero secrets in application code or environment variables
  • Application Insights — real-time monitoring, performance tracking, error alerting

Data pipeline

  • ETL service — Python-based, reads from source systems incrementally (watermark-based CDC), writes Parquet files to Azure Blob
  • DuckDB query engine — in-process analytics engine that queries Parquet files at sub-second speed; no separate data warehouse licence needed
  • Delta Lake format — versioned, ACID-compliant Parquet storage; supports time-travel queries and incremental updates
  • Monthly rollups — pre-aggregated summary tables generated automatically after each ingestion, making time-series queries 10–100× faster

Onboarding

A typical Clarion onboarding for a new customer takes less than one working day — most of that is waiting for data ingestion to complete.

2

Invite users & share dashboards

The admin invites team members, assigns roles, and shares the first AI-generated dashboard. Business users can start asking questions immediately.
